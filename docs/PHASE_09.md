# Phase 09 — Staff & Doctor Operations

## Goal
Create operational dashboards.

## Staff Dashboard
- current patient
- waiting queue
- online/walk-in distinction
- add walk-in
- call next
- skip
- pause/resume
- doctor status

## Doctor Dashboard
- current patient
- next patient
- start
- complete
- daily count

## Acceptance Criteria
A receptionist can run the complete queue without the doctor needing to administer queue operations.
