# Phase 01 — Project Foundation

## Goal
Create the minimal MERN foundation.

## Scope
- React client
- Express server
- MongoDB connection
- environment variables
- health endpoint
- basic project structure

## Acceptance Criteria
- frontend runs
- backend runs
- backend connects to MongoDB
- health endpoint returns success
- no secrets committed to Git

## Do Not Build
- authentication
- queue
- doctor UI
- appointment logic
