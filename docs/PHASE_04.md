# Phase 04 — Clinic, Doctor & Schedule

## Goal
Allow clinic administration to configure doctors and schedules.

## Features
- doctor profile
- qualifications
- specialty
- fee
- clinic
- weekly availability
- breaks
- temporary operational status

## Acceptance Criteria
- recurring schedule can be stored
- lunch/break can be stored
- temporary busy/unavailable status does not overwrite recurring schedule
- doctor profile is visible to patients
