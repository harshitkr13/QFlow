# Phase 12 — Hardening & Release

## Goal
Make QFlow portfolio-ready.

## Checklist
- validation
- authorization review
- duplicate request protection
- appointment conflict testing
- queue concurrency testing
- break/availability edge cases
- no-show/rejoin edge cases
- empty/loading/error states
- production build
- environment configuration
- deployment

## Release Acceptance
Core patient, staff and doctor workflows work end-to-end without manual database edits.
