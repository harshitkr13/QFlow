# Phase 05 — Patient Discovery

## Goal
Build the clean discovery experience.

## Flow
Location -> Specialty -> Doctor List -> Filters -> Doctor Profile

## Filters
- distance
- rating
- experience
- fee
- doctor gender preference
- broad availability

## Important UX Constraint
Do not display operational queue information on doctor discovery cards or the general profile.

## Acceptance Criteria
Patient can discover and compare doctors without seeing queue counts.
